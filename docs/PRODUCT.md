# Product

**NEMDAR Creator** is an AI-assisted marketing media editor that grows from a lightweight branded video/image editor into a complete campaign production system.

The product starts with editing, not generation. This keeps the first release useful, testable and independent from expensive model providers.

Long-term workflow:

`Marketing Brief → Concept → Script → Storyboard → Assets → Edit → Brand Check → Variants → Export/Publish → Performance feedback`
